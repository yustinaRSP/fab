# Birthday Celebration 🎂

Aplikasi ucapan ulang tahun sederhana menggunakan Python dan Streamlit.

## Menjalankan di komputer

1. Pastikan Python sudah terpasang.
2. Buka terminal di folder proyek.
3. Install dependensi:

   ```bash
   pip install -r requirements.txt
   ```

4. Jalankan aplikasi:

   ```bash
   streamlit run app.py
   ```

## Deploy ke GitHub dan Streamlit Community Cloud

1. Buat repository baru di GitHub.
2. Upload `app.py` dan `requirements.txt`.
3. Buka https://share.streamlit.io/
4. Login menggunakan akun GitHub.
5. Pilih **Create app**, lalu pilih repository dan file `app.py`.
6. Klik **Deploy**.

Aplikasi akan mendapatkan tautan web yang bisa dibagikan.
